# Restaurant Page

A simple restaurant website built with **JavaScript**, **Webpack**, and **modular architecture**. My first project built with Webpack.

## Live Demo
[View on GitHub Pages](https://kirilltrs1.github.io/Restaurant-Page/)

## Features
- Tab navigation (Home / Menu)
- Dynamically generated content using JavaScript
- Webpack bundling

## Tech Stack
- HTML5
- CSS3
- JavaScript (ES6 Modules)
- Webpack

##  Build and Deploy
To build and deploy manually:
```bash
npx webpack --mode production
git add dist -f
git commit -m "Deployment commit"
git subtree push --prefix dist origin gh-pages
